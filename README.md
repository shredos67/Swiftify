# Swiftify
swiftify is a spotify client written in swift and rust because electron apps suck.


it uses librespot and rust as a backend. the ui is written in swift. this app is very design focused.


the app has full functionality, lyrics, downloads etc. i also added some of my own features such as a visually pleasing fullscreen player view with audio visualizers.


> [!WARNING]
> this is entirely a hobby project so dont expect everything to work flawlessly


i have taken help from ai to write the swift code since i dont know swift that well and i frankly dont have time to write this app by hand. there are some issues i will fix soon regarding offline downloading and playback sometimes doesnt work due to certain spotify api issues


you can download an app bundle for apple silicon via this repos releases. if you arent on apple silicon clone the repo and build an app bundle using xcode.

> i am very open to suggestions so if you want something added or fixed let me know! :)
